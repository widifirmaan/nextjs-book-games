## Fitur

- **30 Gamified Psychological Activities (`app/level/[id]/page.tsx`)**: Educational reflection exercises divided across 5 Psychological Well-Being (PWB) dimensions:
  - **Dimension 1: Self Acceptance (Levels 1–7)**: Character word search grid (`Level1WordSearch.tsx`), multi-expression facial sketching (`Level2Drawing.tsx`), hope balloons release (`Level3Games.tsx`), mirror reflection, and self-acceptance box.
  - **Dimension 2: Environmental Mastery (Levels 8–12)**: Anxiety elixir calming potion mixing (`Level8Games.tsx`), concentric influence circle, freehand drawing canvas (`Level10Drawing.tsx`), relaxing audio sessions, and emotional splash checkpoints.
  - **Dimension 3: Personal Growth (Levels 13–24)**: Planting wishes on the tree of hope (`Level13Games.tsx`), biggest dream declaration, cloud imagination, sticky notes action planner, and 7 sequential stages of change stairways (`Level18Games.tsx` – `Level24Games.tsx`).
  - **Dimension 4: Purpose in Life (Levels 25–29)**: Self-exploration questionnaire, three-era time wheel (Past, Present, Future), gratitude treasure map, goal compass, and letter to future self.
  - **Dimension 5: Positive Relations (Level 30)**: Multi-flavored ice cream scoop of hope (`Level30IceCream.tsx`) capturing wishes for loved ones and social circles.
- **Sequential Adventure Progression Map (`app/dashboard/siswa/page.tsx`)**: Student dashboard displaying dynamic level completion counts, prerequisite level locks, and achievement badge milestones.
- **Teacher Gradebook & Excel Export (`app/dashboard/guru/page.tsx`)**: Central educator management portal with school and class filtering, student progress tables across all 30 levels with completion status checkmarks, detailed submission response inspection, and 1-click Excel spreadsheet export via SheetJS (`.xlsx`).
- **Unified Role-Based Authentication (`app/login/page.tsx`)**: Credentials authentication powered by NextAuth.js separating Teacher (`GURU`) administrative rights from Student (`SISWA`) gameplay sessions.
- **Relational SQLite Storage (`schema.sql`)**: Relational database schema persisting student progress, level submission JSON maps, session timestamps, and earned achievement badges in the `users` table.
- **HTML5 Canvas Drawing Engine**: Freehand sketch canvas with color palette selection, stroke thickness adjustments, undo history, and base64 data-URL export.

## Tutorial Run Local & Setup

### 1. Prerequisites

- **Node.js**: Version `18.17.0` or higher (`20.x` recommended)
- **npm** or **pnpm**
- **SQLite 3**: Native CLI (`sqlite3`)

### 2. Environment Variables Setup

Create a `.env.local` file in the project root:

```env
NEXTAUTH_SECRET=super_secret_local_dev_key_12345
NEXTAUTH_URL=http://localhost:3000
```

### 3. Installation

```bash
# Clone the repository
git clone https://github.com/widifirmaan/nextjs-book-games.git
cd nextjs-book-games

# Install dependencies
npm install
```

### 4. Database Schema & Seeder Setup

Book Games persists user credentials, gameplay progress, and scores in a relational SQLite table (`schema.sql`):

```sql
CREATE TABLE users (
    id TEXT PRIMARY KEY,
    username TEXT UNIQUE NOT NULL,
    password TEXT NOT NULL,
    role TEXT NOT NULL CHECK(role IN ('GURU', 'SISWA')),
    fullName TEXT,
    email TEXT,
    kelas TEXT,
    schoolName TEXT,
    photoUrl TEXT,
    level INTEGER DEFAULT 1,
    levels TEXT DEFAULT '{}',               -- JSON map of level completions
    indukStartTimes TEXT DEFAULT '{}',      -- Session start timestamps
    indukEndTimes TEXT DEFAULT '{}',        -- Session finish timestamps
    dailySubmissions TEXT DEFAULT '{}',     -- Daily progress records
    awards TEXT DEFAULT '[]',               -- Earned achievement badge IDs
    newAwardsToNotify TEXT DEFAULT '[]',    -- Pending badge notification queue
    createdAt TEXT DEFAULT (datetime('now')),
    updatedAt TEXT DEFAULT (datetime('now'))
);

CREATE INDEX idx_users_role ON users(role);
CREATE INDEX idx_users_username ON users(username);
```

Initialize the SQLite database schema with pre-seeded demo accounts:

```bash
# Initialize schema and seed accounts
sqlite3 local.db < schema.sql

# Or via npm script
npm run db:setup
```

#### Pre-seeded Demo Accounts & Auth Credentials:
- **Teacher Account**: Username `guru` / Password `password` (Access gradebook, analytics, and Excel export)
- **Student Account**: Username `siswa` / Password `password` (Access 30-level adventure map and mini-games)

### 5. Running the Local Server

```bash
# Start Next.js development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
